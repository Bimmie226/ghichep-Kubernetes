# ConfigMap trong Kubernetes 

ConfigMap là 1 đối tượng dùng để lưu trữ dữ liệu cấu hình ở dạng cặp key-value hoặc file 

Manifest: 

```yaml
apiVersion: v1
kind: ConfigMap
metadata: 
  name: ecommerce-backend-aplication-properties-configmap
  namespace: ecommerce
data: 
  aplication.properties: 
    spring.datasource.url=jdbc:mysql://192.168.213.101:3306/full-stack-ecommerce
    spring.datasource.username=ecommerceapp
    spring.datasource.password=StrongPa55WorD
    spring.datasource.driverClassName=com.mysql.cj.jdbc.Driver
    spring.datasource.sql-script-encoding=UTF-8
    spring.jpa.properties.hibernate.globally_quoted_i/dentifiers=true
    spring.jpa.hibernate.ddl-auto=none
    spring.jpa.show-sql=true
    spring.jpa.properties.hibernate.format_sql=true

    spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect

    spring.data.rest.base-path=/api

    allowed.origins=http://192.168.213.101:4200

    spring.data.rest.detection-strategy=ANNOTATED

    okta.oauth2.client-id=0oab0lzwjoN1Rjsar5d7

    okta.oauth2.issuer=https://dev-82108115.okta.com/oauth2/default
```

Cách sử dụng ConfigMap: `ecommerce-backend-deployment.yaml`

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  labels:
    app: ecommerce-backend
  name: ecommerce-backend-deployment
  namespace: ecommerce
spec:
  replicas: 2
  revisionHistoryLimit: 11
  selector:
    matchLabels:
      app: ecommerce
  strategy:
    rollingUpdate:
      maxSurge: 25%
      maxUnavailable: 25%
    type: RollingUpdate
  template:
    metadata:
      labels:
        app: ecommerce-backend
      namespace: ecommerce
    spec:
      containers:
        - image: elroydevops/ecommerce-backend
          imagePullPolicy: Always
          name: ecommerce-backend
          ports:
            - containerPort: 8080
              name: tcp
              protocol: TCP
          volumeMounts: 
            - name: aplication-properties-config-volume
              mountPath: /run/src/main/resources/aplication.properties
              subPath: aplication.properties

      volumes: 
        - name: aplication-properties-config-volume
          configMap: 
            name: ecommerce-backend-aplication-properties-configmap
```
